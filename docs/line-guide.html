⚙️ ขั้นตอนติดตั้ง (ทำครั้งเดียว)

1
เปิดฟีเจอร์ตรวจจับอาการง่วง
ในแอป → ตั้งค่า (Settings) → ตรวจจับอาการง่วง → เปิดสวิตช์ → อนุญาตให้ใช้กล้อง
2
เชิญลูกหลาน แนะนำ: วิธีลิงก์
ตั้งค่า → แจ้งครอบครัวผ่าน LINE → กดปุ่ม “เชิญด้วยลิงก์”
→ ได้ลิงก์ + QR → กด คัดลอกลิงก์ แล้วส่งเข้ากลุ่มไลน์ครอบครัว
ลูกหลานแต่ละคน กดลิงก์นั้นใน LINE → เข้าสู่ระบบ → ขึ้น “✅ เชื่อมต่อสำเร็จ” = เสร็จ (ไม่ต้องพิมพ์รหัสอะไรเลย)
3
ทดสอบ
กดปุ่ม “ทดสอบส่งแจ้งเตือน” → ลูกหลานที่เชื่อมไว้จะได้ข้อความใน LINE ทันที ✅
หรือถ้าปุ่มลิงก์มีปัญหา ใช้วิธีสำรอง
วิธีสำรอง — กรอก LINE User ID เอง
A
แอด Official Account เป็นเพื่อน
ลูกหลานค้นหา / สแกน QR แล้วแอด: 💬 @764txpcs
B
ทักบอท → รับรหัส
พิมพ์ข้อความอะไรก็ได้ส่งไป → บอทตอบ LINE User ID (ขึ้นต้นด้วย U) กลับมา
C
กรอกในแอป
เอารหัส U... มากรอกในช่อง “LINE User ID ของลูกหลาน” → กด เพิ่มลูกหลาน

🔔 เวลาใช้งานจริง ลูกหลานจะได้อะไร

1
แจ้งเตือนง่วง
เมื่อกล้องตรวจเจอผู้สูงอายุง่วง → ส่งข้อความ + ปุ่ม “รับทราบ / กำลังไปดู”
2
เตือนซ้ำอัตโนมัติ
ถ้าไม่มีใครกด “รับทราบ” ภายใน 3 นาที ระบบจะเตือนซ้ำ ⚠️
3
“วันนี้สบายดี 🙂”
ส่งให้วันละครั้ง เพื่อให้อุ่นใจว่าปกติดี (เงียบ ≠ สบายใจ)
⚠️ สำคัญ: ลูกหลานต้องแอด @764txpcs เป็นเพื่อนใน LINE ด้วย ไม่งั้นข้อความแจ้งเตือนจะส่งไม่เข้า (LINE ส่งได้เฉพาะคนที่เป็นเพื่อนกับบัญชีเท่านั้น)
