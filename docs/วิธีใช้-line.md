## ⚙️ วิธีตั้งค่า (ลูกหลานทำบนมือถือผู้สูงอายุ ครั้งเดียว)

### 1) เปิดฟีเจอร์ตรวจจับอาการง่วง
เปิดแอป → **ตั้งค่า (Settings)** → **ตรวจจับอาการง่วง** → เปิดสวิตช์ → อนุญาตกล้อง
- ตั้งความถี่ตรวจได้ (1/2/5 นาที)

### 2) เชิญลูกหลานเข้ารับแจ้งเตือน — เลือกวิธีใดวิธีหนึ่ง

**วิธี A — เชิญด้วยลิงก์ (ง่ายสุด แนะนำ)**
1. ตั้งค่า → **แจ้งครอบครัวผ่าน LINE** → กด **"เชิญด้วยลิงก์"**
2. ได้ลิงก์ + QR → กด **คัดลอกลิงก์** → ส่งเข้ากลุ่มไลน์ครอบครัว
3. ลูกหลานแต่ละคน **กดลิงก์** → ล็อกอิน LINE → ขึ้น **"✅ เชื่อมต่อสำเร็จ"** = เสร็จ
   (ไม่ต้องพิมพ์รหัสอะไรเลย)

**วิธี B — กรอก LINE User ID เอง (สำรอง)**
1. ลูกหลานสแกน QR แอด OA `@764txpcs` เป็นเพื่อน
2. ทักข้อความอะไรก็ได้ไปหา → บอทตอบ **LINE User ID** (ขึ้นต้นด้วย `U`)
3. เอา ID นั้นมากรอกในแอป (ช่อง "LINE User ID ของลูกหลาน") → กด **เพิ่มลูกหลาน**

### 3) ทดสอบ
กด **"ทดสอบส่งแจ้งเตือน"** → ลูกหลานที่เชื่อมไว้จะได้ข้อความใน LINE ทันที

## 🔔 เวลาใช้งานจริง ลูกหลานจะได้อะไรบ้าง

1. **แจ้งเตือนง่วง** — เมื่อกล้องตรวจเจอผู้สูงอายุง่วง จะส่งข้อความ + ปุ่ม **"รับทราบ / กำลังไปดู"**
2. **เตือนซ้ำ (escalation)** — ถ้าไม่มีใครกด "รับทราบ" ภายใน 3 นาที ระบบเตือนซ้ำ ⚠️
3. **"วันนี้สบายดี 🙂"** — ส่งวันละครั้ง เพื่อให้อุ่นใจว่าปกติ (เงียบ ≠ สบายใจ)
